# コメント欄アンケート ＋ Pong

探究「SNSにおける他者の意見・いいね数が意見形成に与える影響」で使うWebアプリです。
ニュース記事とコメント欄を模したページを3つ見てもらい、コメント・いいね・返信をしてもらいます。回答を終えた人はPongで遊べます。

- フレームワーク：Next.js 15（App Router）＋ TypeScript
- データ保存：Upstash Redis（**必須**。つながっていないと Vercel 上ではエラーになります）
- オンライン対戦：Ably
- 記事とコメント：`content/articles.ts`
- フォーム作成：`gas/create_form.gs`
- GitHubへの反映（termux）：`tools/csup.bash`

## 実験のしくみ（欺瞞なし）

最初の画面で「コメントといいね数はこの調査のために用意したもので、実在の人の投稿ではない」と伝えます。

| 記事 | 内容 | A群のコメント欄 | B群のコメント欄 |
|---|---|---|---|
| 1 | スマホ2時間条例（身近な話題） | 賛成が多数・いいね多 | 反対が多数・いいね多 |
| 2 | リーネ島の消灯ルール（架空の話題） | 反対が多数 | 賛成が多数 |
| 3 | 学校プールの民間委託（いいね vs 説得力） | 賛成＝長文・いいね少／反対＝短文・いいね多 | 逆 |

- 開始した人は、人数が少ないほうの群に入ります（同数なら無作為）。
- 各記事で**自分のコメント1件は必須**。いいね・返信は自由です。
- 返信は強制しませんが、できるだけしてもらうために：
  - 最初の説明とコメント欄の上で「気になったコメントには返信してみよう」と伝える
  - その記事でまだ返信していないまま「次へ」を押すと、1回だけ「返信してみませんか？」と出る（「このまま次へ」で進める）。どちらを選んだかも記録する
- 参加者自身のコメントや返信は、ほかの参加者には表示されません。

## 「回答済み」の判定

- 参加者は cookie（ランダムなID）で見分けます。同じブラウザなら、開き直しても続きから（終了済みなら完了コードだけ）になります。
- 終了すると、**署名付きの完了cookie**も保存します。データベースを読めなかったときでも「回答済み」と判定でき、改ざんはできません（署名の鍵は `ADMIN_KEY`）。
- コメント・返信の「1回だけ」は Redis の集合で判定するので、ボタンを連打したり同時に送ったりしても1回しか通りません。

## デプロイ（Vercel）

環境変数：
- `ADMIN_KEY`：12文字以上の自分しか知らない文字列（データ取り出し・cookieの署名に使う。**途中で変えると完了cookieが無効になる**ので本番中は変えない）
- `ABLY_API_KEY`：AblyのAPIキー（Pongのオンライン対戦用）
- Upstash Redis をつなぐと `KV_REST_API_URL` などが自動で入る

## データの取り出し

- 1人1行：`https://（URL）/api/export?key=管理キー&type=summary`
  - 記事ごとに、コメント・滞在秒・**どの種類のコメントにいいねしたか**（多数派／少数派／長文／短文／中立の数）・返信・返信のすすめへの反応
- 操作の記録：`https://（URL）/api/export?key=管理キー&type=logs`
- 完了コードで、フォームの回答とつなげます。

**分析の例**
- 記事1・2：フォームの「考え（1〜5）」をA群とB群で比べる（コメント欄の多数派の方向に寄ったか）
- 記事1と2の差：知っている話題と知らない話題で、寄り方が違うか
- 記事3：長文側と短文（いいね多）側のどちらに考えが寄ったか、どちらにいいねしたか
- 「いいね_多数派」と「いいね_少数派」：いいねも多数派に集まったか
- アプリのコメントの内容と、フォームの考えのずれ（人に見せる意見と本音）

## Pong

- 終了画面の一番下の小さな「暇？」から。回答を終えた人だけ遊べます。7点先取。
- CPUと対戦（3段階）／2人で対戦（同じ端末）／オンライン対戦（おまかせ・4けたの部屋番号）
- ブラウザやAndroidの「戻る」で、ゲーム → メニュー → アンケートの終了画面 の順に戻ります。
- オンライン対戦中に3秒以上ほかのタブやアプリに移ると、対戦を終了して相手に知らせます。
- 画面はウィンドウに収まる一番大きいサイズ（8:5）。中の座標は 800×500 で共通なので、画面の大きさが違う相手とも公平に対戦できます。
- 文字はピクセルフォント DotGothic16（SIL Open Font License）。
